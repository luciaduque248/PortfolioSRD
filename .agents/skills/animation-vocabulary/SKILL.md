# Animation Vocabulary

Project-local adaptation of Emil Kowalski's `animation-vocabulary` skill (MIT). Upstream: https://github.com/emilkowalski/skills/tree/main/skills/animation-vocabulary

Use precise terms when discussing motion. Preferred vocabulary includes: fade, slide, scale in, pop in, reveal, stagger, orchestration, translate, rotate, 3D tilt, perspective, transform origin, origin-aware animation, crossfade, continuity transition, morph, shared-element transition, layout animation, accordion/collapse, direction-aware transition, scroll reveal, parallax, press/tap feedback, drag, swipe to dismiss, rubber-banding, easing, ease-out, ease-in-out, spring, damping, momentum, velocity, interruptible animation, loop, pulse, float, idle animation, blur, clip-path, mask, skeleton/shimmer, number ticker, frame rate, jank, compositing and reduced motion.

When a requested effect is ambiguous, name the best match first and distinguish 1–2 close alternatives. Do not invent terminology. This skill names effects; it does not decide whether they should be used or implement them.
